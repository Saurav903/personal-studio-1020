# personal Studio 1020

## Public-facing description

A personal finance micro-app that treats money planning as a rehearsal rather than a restriction. personal Studio 1020 gives people a clear daily runway to their next pay day, then lets them model the little real-life decisions that make a plan feel human.

## Value proposition

Most budgeting tools show a ledger after the fact. Studio 1020 answers the more useful question before a purchase: “If I do this, how does the rest of my week feel?” The spend rehearsal turns that answer into a visible daily amount, without requiring bank connections or an account.

## Stack

React, TypeScript, Vite, Lucide icons, plain responsive CSS, and Vitest. The experience is entirely local-first and ships with useful demo data.

## Validation result

Run after install:

- `npm run lint`
- `npm run test`
- `npm run build`

All project code is designed to produce a static `dist/` deployment bundle with no secrets or paid-service dependency.
